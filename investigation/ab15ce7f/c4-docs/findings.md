## FEATURE-BY-FEATURE GAP ANALYSIS

### 1. CROSS-REFERENCES (Critical — User Priority #1)

#### NT (John-1) Implementation:
- **Inline xref pills** per verse: `<span class="xref-pill" onclick="showXrefPopup(this)" data-ref="..." data-es="..." data-gr="..." data-lxx="...">`
- **3 data attributes** embedded: `data-es` (Spanish RVR1909), `data-gr` (Greek NT or WLC Hebrew for OT refs), `data-lxx` (Septuagint for OT refs)
- **Side panel popup** (`#xrefPopup`): 380px fixed panel slides in from right, shows:
  - Reference title (h3)
  - For OT refs: WLC Hebrew (RTL) + LXX Greek labels
  - For NT refs: Greek label
  - Spanish text (RVR1909)
  - BibleGateway link
  - Shared vocabulary indicator (highlights common Greek words)
- **Sidebar** (left): Lists all xrefs by verse, clickable items also trigger the popup
- **Badge button** per verse: `🔗 8 refs` toggles collapsed pill container

#### OT (Proverbs-13) Implementation:
- **Simple text entries**: `<div class="xref-entry"><strong>Proverbs 15:5</strong>: El necio...</div>`
- **Spanish only** — no Greek, no Hebrew, no English
- **No popup** — just shows/hides a collapsed div with static text
- **Sidebar** exists but calls a basic `showXrefPopup(ref, text)` that creates a small bottom-right popup with just ref + text

#### Data Gap:
- `chapter_data["xrefs"]` for OT has `{"es": "...", "gr": ""}` — the `gr` field is **empty for OT-to-OT references**
- The `_lookup_ref_text()` function in study_html_generator tries MorphGNT/SBLGNT/LXX/WLC but the unified generator doesn't call it — it uses whatever `gather_chapter_data` provides
- **Missing entirely**: English (KJV/BSB) text — no version queries it

#### USER REQUIREMENT: Cross-refs must show 4 languages: Spanish (RVR), Hebrew (WLC), Greek (LXX or MorphGNT), English (KJV/BSB)

## KEY ARCHITECTURAL NOTE

The NT John-1 file was generated by an older/different pipeline that embeds xref data directly in HTML data attributes. The current `unified_html_generator.py` puts xrefs in the JS `D` object and renders them as simple text divs. The recommended approach is to:

1. Keep xrefs in the `D` object (it's already there with the data)
2. Render xref pills from JS at page load (like morphology words are rendered)
3. Add the popup panel to the body HTML
4. This avoids bloating HTML with duplicate data in attributes

Alternatively, render xref pills server-side (like NT does) with data attributes for a simpler JS implementation — either approach works.
