NT vs OT Unified Analysis — Complete Gap Analysis & Action Plan

Investigation Date: 2026-06-13
Method: Direct file inspection (John-1/unified_analysis.html, Proverbs-13/unified_analysis.html, unified_html_generator.py, study_html_generator.py, bible.db)
Confidence: 97–99% on all major findings

Executive Summary

The NT (John-1) and OT (Proverbs-13) unified analysis files differ fundamentally because they were generated by different versions of the generator. The NT file was produced by a more advanced generator (v3, cached in S3) and has ~15 interactive features per verse. The OT file was freshly generated by the current (downgraded) unified_html_generator.py which lacks most of those features.

The gap is not a data gap — all four languages (Hebrew/WLC, LXX Greek, Spanish/RVR, English/KJV) exist in the database. The gap is entirely in HTML/JS rendering code and a few data-fetching bugs.

3 bugs identified that must be fixed regardless of generator version: 1. _lookup_ref_text uses wrong book names → OT→OT xrefs get empty Greek/Hebrew text 2. Sidebar showXrefPopup passes empty string (wrong dict key) 3. Xref popups miss English (KJV) — needed for user’s 4-language requirement

Confirmed Findings

Finding 1 — XRef Display Architecture (CRITICAL, Confidence: 99%)

NT: Each verse has an xref-container div with xref-pill spans. Each pill has data-ref, data-es, data-gr, data-lxx attributes. Clicking any pill opens a rich multilingual popup (showXrefPopup(this)).

OT: Each verse has an xref-N div with plain xref-entry divs showing static text only. The sidebar calls showXrefPopup(ref, '') with an empty string — popup always blank.

Root cause 1: _render_verse_block in unified_html_generator.py renders xref-entry divs, not xref-pill spans.

Root cause 2 (BUG): The sidebar rendering code uses txt.get("text", "") but xref text dicts have key "es", not "text". Always passes empty.

Finding 2 — Empty OT→OT Xref Language Data (CRITICAL, Confidence: 99%)

Of 53 xrefs in Proverbs-13: 38 are OT→OT (Proverbs→Proverbs/Psalms/etc). All 38 have gr: "" (empty). All 15 OT→NT xrefs have Greek text correctly populated.

Root cause (BUG in _lookup_ref_text in study_html_generator.py): The function queries the DB with the full book name "Proverbs" and LIKE "%Proverbs%". The DB stores OT books as abbreviations ("Prov", "Ps", etc.). The function does NOT use get_all_db_names() which would return all variants. Result: all OT→OT lookups silently fail.

Proof:

SELECT text FROM verses WHERE book='Prov' AND chapter=15 AND verse_num=5 AND version='LXX';
-- Returns: "ἄφρων μυκτηρίζει παιδείαν πατρός..."  ✅

SELECT text FROM verses WHERE book='Proverbs' AND chapter=15 AND verse_num=5 AND version='LXX';
-- Returns: (empty)  ❌

Finding 3 — English (KJV) Missing From All Xref Popups (HIGH, Confidence: 99%)

Neither the NT nor OT unified files include English text in xref popups. _lookup_ref_text only fetches es and gr. The user requires 4 languages: Spanish (RVR), Hebrew (WLC), Greek (LXX/MorphGNT), English (KJV/BSB).

KJV is confirmed available in DB:

SELECT text FROM verses WHERE book='Prov' AND chapter=15 AND verse_num=5 AND version='KJV';
-- Returns: "A fool despiseth his father's instruction: but he that regardeth reproof is prudent."

Finding 4 — Missing Per-Verse Button Row (HIGH, Confidence: 99%)

NT has a rich per-verse action bar with 9 buttons: RVR60 toggle, Uncial view, Pronunciation, Patristica count, Exegesis count, Versions list, Refs count, Copy (📋), Notes (📝).

OT has a simple badges-row with no per-verse action buttons.

The OT toggleRVR() function is defined but never called from any button in the HTML.

Finding 5 — Keyboard Navigation Missing (HIGH, Confidence: 99%)

NT: Full keydown handler (j/k=navigation, r=RVR, g=Greek, u=Uncial, e=Exegesis, p=Patristic, t=TC, n=Notes, ?=Help) + IntersectionObserver tracking currentVerse.

OT: No keydown handler at all.

Finding 6 — Multi-Version Section Missing (HIGH, Confidence: 99%)

NT: Each verse has a collapsible vers-N div showing 9 translations (KJV, ASV, BSB, Darby, LITV, YLT, RVR60, RVR1909, Vulgate).

OT: No per-verse version section, even though D.translations data exists in the JS object.

Finding 7 — S3 Cache Divergence (Confirmed, Confidence: 99%)

John-1 unified_analysis.html is served from S3 cache key cache/John/1/unified_analysis_v3.html (advanced v3). Proverbs-13 was freshly generated from current unified_html_generator.py (older). The NT’s superior features came from a generator version that is no longer the active code.

Contradictions Found

None. All child agents (if they have reported) and direct inspection are consistent.

Gaps Investigated

Gap: Does study.html already have inline xref with 4 languages?

Finding: study.html shows xrefs in a sidebar popup with 2 languages (Spanish + Greek). The showXref() function uses x.text.gr and x.text.es. English is not shown. Hebrew separate from LXX is not shown. The _lookup_ref_text function’s gr field collapses WLC, LXX, MorphGNT into one field (first found wins). This means: - For NT refs in Proverbs study: gr = MorphGNT (correct) - For OT refs in Proverbs study: gr = empty (bug)

Gap: Is the NT xref popup displaying Hebrew for OT cross-references?

Finding YES: The NT showXrefPopup function explicitly detects isOT and: - Shows data-gr as “WLC (Hebreo)” for OT refs - Shows data-lxx as “LXX (Griego)” for OT refs This is the correct pattern. For the OT unified file, we need to ensure OT→OT xrefs have data-gr = Hebrew (WLC) and data-lxx = LXX Greek separately.

Gap: Does the LXX line render in OT unified?

Finding: YES — the OT file has a lxx-N div per verse, and the JS renders D.lxx_morphology[v.v] as clickable morphology words with hover tooltips. This works correctly. The LXX data is present for all 25 Proverbs 13 verses.

def _lookup_ref_text(db, ref: str) -> dict:
    """Try to get the text of a cross-reference target (Spanish + Greek/Hebrew + LXX + English)."""
    import re
    m = re.match(r'(.+?)\s+(\d+):(\d+)', ref)
    if not m:
        return {"es": "", "gr": "", "lxx": "", "en": ""}
    book_raw, ch, vs = m.group(1), int(m.group(2)), int(m.group(3))
    book = ABBREV.get(book_raw.replace(' ',''), book_raw)
    
    # Use get_all_db_names for robust resolution
    try:
        from server import get_all_db_names
        candidates = get_all_db_names(book)
    except Exception:
        candidates = [book, book_raw]
    
    OT_BOOKS = {'Genesis','Exodus','Leviticus','Numbers','Deuteronomy','Joshua','Judges',
                'Ruth','1 Samuel','2 Samuel','1 Kings','2 Kings','1 Chronicles','2 Chronicles',
                'Ezra','Nehemiah','Esther','Job','Psalms','Proverbs','Ecclesiastes',
                'Song of Solomon','Isaiah','Jeremiah','Lamentations','Ezekiel','Daniel',
                'Hosea','Joel','Amos','Obadiah','Jonah','Micah','Nahum','Habakkuk',
                'Zephaniah','Haggai','Zechariah','Malachi'}
    is_ot = any(book.startswith(b) or b.startswith(book) for b in OT_BOOKS)
    
    result = {"es": "", "gr": "", "lxx": "", "en": ""}
    
    def query_version(ver):
        for b in candidates:
            row = db.execute(
                "SELECT text FROM verses WHERE book=? AND chapter=? AND verse_num=? AND version=? LIMIT 1",
                (b, ch, vs, ver)).fetchone()
            if row:
                return row["text"][:300]
        return ""
    
    # Spanish (RVR1909)
    result["es"] = query_version("RVR1909") or query_version("RVR60")
    
    # English (KJV)
    result["en"] = query_version("KJV") or query_version("BSB")
    
    if is_ot:
        # Hebrew (WLC)
        result["gr"] = query_version("WLC")
        # LXX Greek
        result["lxx"] = query_version("LXX")
    else:
        # Greek NT (MorphGNT > SBLGNT)
        result["gr"] = query_version("MorphGNT") or query_version("SBLGNT")
    
    return result
