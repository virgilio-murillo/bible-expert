Gaps Identified and Investigated

Investigated: All WLC verse_num values are integers (1 to 176 max). No fractional verse numbers in WLC. LXX has edge cases (SusOG verse_num=6062) but these are apocryphal variant texts. Canonical OT books have normal integer verse_nums. No bug.

Gap: Is the Hebrew Strong’s lexicon accessible for WLC word lookups?

Investigated: The gather_chapter_data morphology section builds norm_lex keyed by Strong’s number (lx["strongs"]). For WLC words with no direct lemma match, it falls back to lex = lex_map.get(r["strongs"], {}). The Hebrew lexicon has 8,674 entries. Works correctly.

function explainHebrewMorph(code, form, lemma) {
  const lang = code[0] === 'H' ? 'Hebreo' : 'Arameo';
  // Strip slash-separated prefixes for POS detection: "HC/Vqw3ms" → main code after last slash
  const main = code.includes('/') ? code.split('/').pop() : code.substring(1);
  const pos = main[0];
  const posNames = {'N':'Sustantivo','V':'Verbo','A':'Adjetivo','P':'Pronombre',
                    'R':'Preposición','C':'Conjunción','T':'Artículo/Partícula','D':'Adverbio','S':'Sufijo'};
  let h = `<strong style="font-family:'SBL Hebrew',serif;font-size:1.2rem">${form}</strong><br>`;
  h += `<span style="font-size:0.78rem;color:#555">${lang}</span><br>`;
  
  if (pos === 'V') {
    const stems = {'q':'Qal (simple activo)','N':'Nifal (simple pasivo/reflexivo)',
                   'p':'Piel (intensivo activo)','P':'Pual (intensivo pasivo)',
                   'h':'Hitpael (reflexivo intensivo)','H':'Hofal (causativo pasivo)',
                   'i':'Hifil (causativo activo)'};
    const conjs = {'p':'Perfecto (acción completada)',
                   'i':'Imperfecto (acción continua/futura)',
                   'w':'Wayyiqtol (narrativo pasado: "y...entonces")',
                   'v':'Imperativo (orden/mandato)',
                   'r':'Participio activo','s':'Participio pasivo',
                   'c':'Cohortativo (deseo 1ª pers)',
                   'j':'Yusivo (deseo 3ª pers)'};
    const stem = stems[main[1]] || main[1];
    const conj = conjs[main[2]] || main[2];
    h += `<strong>Verbo</strong> — ${stem}<br><span style="font-size:0.8rem">${conj}</span>`;
  } else if (pos === 'N') {
    const types = {'c':'común','p':'propio','g':'gentilicio'};
    const genders = {'m':'masc.','f':'fem.','b':'ambos','c':'común'};
    const numbers = {'s':'sing.','p':'plur.','d':'dual'};
    const states = {'a':'absoluto','c':'constructo','d':'determinado'};
    h += `<strong>${posNames[pos]}</strong> — ${types[main[1]]||''} ${genders[main[2]]||''} ${numbers[main[3]]||''} ${states[main[4]]||''}`;
  } else {
    h += `<strong>${posNames[pos] || pos}</strong>`;
  }
  return h;
}
